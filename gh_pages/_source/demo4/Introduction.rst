Industrial Calibration Introduction
===================================

Goal
----
In these exercises, an existing ROS system will be modified to perform an eye-hand, or wrist, calibration.  The precise position of a camera relative to a robot will be determined, enabling precise movements relative to objects observed by the camera.  The configuration files, modifications, and tools from industrial calibration will each be explained in turn.

Objectives
----------
* Understand the concepts behind eye-hand calibration
* Learn how to configure a system to use the industrial calibration library
* Learn which parameters are most likely to be modified between systems
* Identify common speed bumps to calibration and how to recognize a good calibration
* Execute the calibration process
